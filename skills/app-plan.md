# App planning playbook

Goal: [what should this app do?]
Audience: [who is it for?]
Platform: [web / Windows / other]
Constraints: [budget, privacy, tools, deadline]

1. Restate the goal and identify missing requirements.
2. Separate the smallest useful release from the roadmap.
3. Propose a maintainable architecture and explain tradeoffs.
4. Break implementation into verifiable tasks.
5. Define tests, accessibility checks, and acceptance criteria.
6. Ask before installing software, using paid services, publishing, or destructive actions.

Do not claim code was run or verified without evidence. A skill supplies instructions, not permission to execute commands or access data.
