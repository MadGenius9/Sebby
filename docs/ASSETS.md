# Original pal assets

`public/orbit.png` is the standalone transparent 1024×1024 render from the selected editable Blender Orbit concept, supplied separately from the comparison board. It is not cropped from a mockup. `build/icon.ico` is a deterministic format/resolution conversion of that same PNG, containing 16–256px icon sizes; no new visual identity was synthesized.

The parent task retains editable sources at `/workspace/shared/sebby_concepts/sebby_orbit.blend` and `sebby_orbit.glb`. They are not runtime dependencies or embedded in this source checkpoint. Sebby is the app name; Orbit describes the character design.

`docs/ui-concept.png` is a UI design reference generated by the built-in image generation tool, not a functioning UI screenshot. Its prompt requested a complete dark-navy/ice-blue Windows companion surface with Chat/Workspace/Memory/Skills/Connections/Personality, offline AI disclosure, 3 playbooks, bottom composer, and at-a-glance inspector. The app uses code-native controls and the separately selected original Orbit render, not the concept screenshot as UI.

The 0.4 runtime also includes local palette-ready GLBs and PNG fallbacks under `public/pals/`, with provenance manifests in `docs/`. Body/accent/glow materials are recolored in Three.js; emitted light keeps its authored intensity. Blender source scenes remain separate editable deliverables, not runtime dependencies. Assets were procedurally authored for this project, not extracted from third-party character meshes. This is provenance documentation, not completed commercial trademark/licensing clearance.
