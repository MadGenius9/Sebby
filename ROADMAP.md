# Sebby roadmap

Living proposal. Implemented features are listed in README; every item below beyond phase 1 is future work at this checkpoint. Safety, automated tests, accessibility, and honest status are continuous, not a final afterthought.

1. **Foundation (current):** desktop shell, selected Orbit look, local memory, personality preferences, bundled playbooks, controlled project-folder reading and create-only notes.
2. **Real AI:** secure provider setup, streaming text, cancellation, explicit context, history, budgets and usage reporting. Voice exploration can begin after reliable text; rich voice arrives in phase 6. No paid calls or new credentials without authorization.
3. **Development workspace:** approved read/edit/build/test, diff review, previews, recovery/undo, command policy and sandbox boundaries. **First useful app-developer milestone is the end of phase 3.**
4. **Skills and connections:** extensible verified skill registry, scoped GitHub first, then other connectors/MCP. Per-tool permissions; no bundled broad trust.
5. **Specialist agents:** durable task queue, orchestration, specialist roles, cancellation, restart recovery and an evidence trail. Roles do not create privileges.
6. **Companion:** voice, Orbit expressions, opt-in reminders, controlled desktop/browser automation, optional cloud continuation. Microphone, notifications, remote data and cloud costs require explicit controls.
7. **Release quality:** Windows installer and signing, updates, backup/export, accessibility, security review, end-to-end Windows validation.

Potential improvements: provenance for remembered facts, project-specific budgets and permission summaries, and reversible changes by default. These should improve clarity and control rather than quietly expand access.
